# DevOps лабораторные на проекте idioma

Автор: Денис Пожидаев, GitHub `ig1rkas`.

В основе — собственный проект idioma: React + Vite, FastAPI + SQLAlchemy,
PostgreSQL. Лабораторные используют одну сохранённую копию исходников в
`lab0/app`, поэтому изменение учебной инфраструктуры не затрагивает основной сайт.

| Папка | Работа | Отчёт |
|---|---|---|
| `lab0` | Свой сервис и сохранение данных | [README](lab0/README.md) |
| `lab1` | nginx, HTTPS, балансировка и отказоустойчивость | [README](lab1/README.md) |
| `lab2` | Docker, сравнение образов и Compose | [README](lab2/README.md) |
| `lab3` | CI/CD и откат релиза, локальные проверки | [README](lab3/README.md) |

Требования: Docker Engine / Docker Desktop с Compose, Python 3, curl, OpenSSL,
Bash. Команды в отчётах выполняются из папки соответствующей лабораторной.
Все опубликованные порты привязаны к `127.0.0.1`. Пароли с префиксом `local-`
являются открытыми учебными значениями для изолированного стенда.
Telegram, реальные `.env`, дампы БД и пользовательские сессии не переносятся.

В каждой папке `evidence` находятся результаты фактических проверок.
Даты коммитов и замеры соответствуют времени выполнения команд.

Все три работы выполнены и проверены. В лабораторной 1 дополнительно проверена
защита конфигурации на собственном localhost-стенде, в лабораторной 2 выполнены
автовосстановление, демонстрация OOM и проверка CPU-квоты под нагрузкой.

Снимки протоколов в отчётах являются отображением сохранённого фактического
вывода команд. Рядом сохранены оригинальные TXT/JSON/BuildKit-логи; HTML-снимки
содержат SHA-256 исходных текстов. Скриншоты приложения сняты настоящим браузером.

Лабораторная 3 проверена локально; код, отчёт и `.github/workflows` включены
в репозиторий. Для выполнения workflow на GitHub нужны self-hosted runner
с меткой `idioma-lab3` и secrets, перечисленные в отчёте. При подготовке исправлены
три HIGH-уязвимости Alpine-пакетов фронтенда в Dockerfile лабы 2.
