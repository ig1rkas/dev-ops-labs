# idioma favicon pack

Готовый favicon-пак для сайта idioma.

## Файлы

- `favicon.ico` — основной favicon для браузеров.
- `favicon-16x16.png` — маленькая PNG-версия.
- `favicon-32x32.png` — стандартная PNG-версия.
- `favicon-48x48.png`, `favicon-64x64.png`, `favicon-128x128.png`, `favicon-256x256.png` — дополнительные размеры.
- `apple-touch-icon.png` — иконка для iOS, 180x180.
- `android-chrome-192x192.png` — PWA / Android, 192x192.
- `android-chrome-512x512.png` — PWA / Android, 512x512.
- `favicon-transparent-192x192.png`, `favicon-transparent-512x512.png` — прозрачная версия без круглой подложки.
- `site.webmanifest` — manifest для PWA.
- `favicon-html-snippet.txt` — готовый HTML-код для `<head>`.

## Как подключить

Скопируйте файлы в папку `public/` проекта и добавьте содержимое `favicon-html-snippet.txt` в `<head>`.
